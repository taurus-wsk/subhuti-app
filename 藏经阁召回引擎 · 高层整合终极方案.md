# 藏经阁召回引擎 · 高层整合终极方案

>
> 版本：v1.0‑Final
> 架构原则：职责单一、通路解耦、可开关、可控扩散范围、查询只读，学习逻辑后置异步

## 一、整体架构总览

### 四大召回数据源

1. **BaseSearch 基础检索**：关键词 匹配，产出原始种子切片 `Seed0`,可以有多个种子
2. **SpaceDepthStrategy 静态空间通路**：仅依靠物理目录树(阁‑柜‑抽屉)召回邻居；实体只做层内排序，**不驱动扩散**
3. **GraphPassageStrategy 一阶图谱BFS**：原始种子切片实体作为起点，遍历 Manual(手动/LLM)、Learned(共现熟练度)两类实体边
4. **GraphPassageStrategy 二阶图谱BFS（可选）**：空间通路输出切片作为种子，再跑一轮图谱，整体分数额外衰减，避免权重压倒原始线索

### 硬性约束规则

1. 禁止图谱召回结果再投喂空间策略，防止空间无规则跨文件夹扩散
2. 空间策略排序锚点实体集合全程固定，使用**原始种子切片实体集合**，不动态追加新实体
3. 所有动态学习边(Learned)生成逻辑为**后台异步任务**，查询链路只读，不实时修改内存图谱
4. 每条切片在候选池中只保留最大bonus分值，不重复累加分数

```
/// 基础检索单条结果
#[derive(Debug,Clone)]
pub struct BaseHit{
    pub chunk_id:ChunkUuid,
    pub base_score:f32
}

/// 空间策略返回结果
#[derive(Debug,Clone)]
pub struct SpaceHit{
    pub chunk_id:ChunkUuid,
    pub bonus_score:f32,
    pub tree_distance:u32
}

/// 图谱策略返回结果
#[derive(Debug,Clone)]
pub struct GraphHit{
    pub chunk_id:ChunkUuid,
    pub bonus_score:f32,
    pub edge_sources:Vec<RelationSource>,
    pub entity_path:Option<Vec<EntityUuid>>
}

/// 最终合并后的通用候选项
#[derive(Debug,Clone)]
pub struct Candidate{
    pub chunk_id:ChunkUuid,
    pub base_score:f32,
    pub bonus_score:f32,
    /// 记录来自哪些扩展通路，用于调试
    pub source_flags:Vec<RetrieveSource>
}

#[derive(Debug,Clone,PartialEq,Eq)]
pub enum RetrieveSource{
    Base,
    Space,
    GraphFirstPass,
    GraphSecondPass
}
```

## 四、引擎高层主入口伪代码

```
///藏经阁召回主入口
///query:用户检索输入
///config:召回配置
pub async fn library_retrieve(
    &self,
    query:&str,
    config:&LibraryRetrieveConfig
)->Vec<Candidate>
{
    //==================== 阶段1：基础检索，拿到原始种子 ====================
    let base_hits:Vec<BaseHit> = self.base_search.search(query,config.base_top_k).await;
    let seed0:Vec<ChunkUuid> = base_hits.iter().map(|h|h.chunk_id).collect();

    //提取【全局固定根实体集合】，空间排序全程只使用这一份实体
    let root_entity_set:HashSet<EntityUuid> = self
        .graph_strategy
        .get_entities_of_chunks(&seed0);

    //候选池Map，chunk_id -> Candidate
    let mut candidate_pool:HashMap<ChunkUuid,Candidate> = HashMap::new();

    //1.1 将基础检索结果写入候选池
    for hit in base_hits{
        candidate_pool.insert(hit.chunk_id,Candidate{
            chunk_id:hit.chunk_id,
            base_score:hit.base_score,
            bonus_score:0.0,
            source_flags:vec![RetrieveSource::Base]
        });
    }

    //==================== 阶段2：并行一阶扩展通路 ====================
    //通路A：静态空间召回
    let space_hits:Vec<SpaceHit> = if config.space_enable{
        self.space_strategy.expand(
            &seed0,
            &root_entity_set,
            config.space_max_tree_distance,
            config.space_per_level_limit
        )
    }else{
        Vec::new()
    };

    //通路B：图谱一阶BFS（原始种子）,分数倍率=1.0
    let graph_cfg = GraphExpandConfig{
        max_depth:config.graph_max_depth,
        max_result:config.graph_max_global_result,
        decay_factor:config.graph_decay_factor,
        enable_manual_edge:config.enable_manual_edge,
        enable_learned_edge:config.enable_learned_edge,
        learned_scale:config.learned_edge_scale
    };
    let graph1_hits:Vec<GraphHit> = self.graph_strategy.expand(
        &seed0,
        &graph_cfg,
        1.0
    );

    //==================== 阶段3：可选二阶图谱扩展(空间切片投喂图谱) ====================
    let mut graph2_hits:Vec<GraphHit> = Vec::new();
    if config.graph_second_pass_from_space && !space_hits.is_empty(){
        let space_chunk_seeds:Vec<ChunkUuid> = space_hits.iter()
            .map(|x|x.chunk_id)
            .collect();
        graph2_hits = self.graph_strategy.expand(
            &space_chunk_seeds,
            &graph_cfg,
            config.second_pass_score_decay
        );
    }

    //==================== 阶段4：合并所有扩展结果到候选池 ====================
    //4.1 合并空间通路
    for sh in space_hits{
        candidate_pool.entry(sh.chunk_id)
            .and_modify(|c|{
                c.bonus_score = c.bonus_score.max(sh.bonus_score);
                if !c.source_flags.contains(&RetrieveSource::Space){
                    c.source_flags.push(RetrieveSource::Space);
                }
            })
            .or_insert(Candidate{
                chunk_id:sh.chunk_id,
                base_score:0.0,
                bonus_score:sh.bonus_score,
                source_flags:vec![RetrieveSource::Space]
            });
    }

    //4.2 合并一阶图谱
    for gh in graph1_hits{
        candidate_pool.entry(gh.chunk_id)
            .and_modify(|c|{
                c.bonus_score = c.bonus_score.max(gh.bonus_score);
                if !c.source_flags.contains(&RetrieveSource::GraphFirstPass){
                    c.source_flags.push(RetrieveSource::GraphFirstPass);
                }
            })
            .or_insert(Candidate{
                chunk_id:gh.chunk_id,
                base_score:0.0,
                bonus_score:gh.bonus_score,
                source_flags:vec![RetrieveSource::GraphFirstPass]
            });
    }

    //4.3 合并二阶图谱
    for gh in graph2_hits{
        candidate_pool.entry(gh.chunk_id)
            .and_modify(|c|{
                c.bonus_score = c.bonus_score.max(gh.bonus_score);
                if !c.source_flags.contains(&RetrieveSource::GraphSecondPass){
                    c.source_flags.push(RetrieveSource::GraphSecondPass);
                }
            })
            .or_insert(Candidate{
                chunk_id:gh.chunk_id,
                base_score:0.0,
                bonus_score:gh.bonus_score,
                source_flags:vec![RetrieveSource::GraphSecondPass]
            });
    }

    //==================== 阶段5：全局打分、排序 ====================
    //总分公式 = base_score + bonus_score
    let mut list:Vec<Candidate> = candidate_pool.into_values().collect();
    list.sort_by(|a,b|{
        let sa = a.base_score + a.bonus_score;
        let sb = b.base_score + b.bonus_score;
        sb.partial_cmp(&sa).unwrap()
    });

    Ok(list)
}
```

```
        //4.每层截断 per_level_limit
```

## 七、后台异步学习任务（独立进程/协程，不阻塞查询）

>
> 查询链路只读，学习任务在每次召回完成之后后台执行

```
///召回完成后，后台调用，更新熟练度Learned边
pub async fn post_retrieve_learn_task(
    &mut self,
    final_candidates:&[Candidate]
){
    let chunk_ids:Vec<ChunkUuid> = final_candidates.iter().map(|c|c.chunk_id).collect();
    //1.取出结果里面全部实体
    let entities = self.graph_strategy.get_entities_of_chunks(&chunk_ids);
    //2.实体两两共现，更新Learned熟练度边
    self.graph_strategy.observe_entity_cooccurrence(&entities);
    //3.定时老化任务：衰减长期未共现的Learned边权重
}
```

## 八、总分计算公式

```
total_score = base_score + bonus_score
```

- `base_score`：基础检索得分(关键词/向量)
- `bonus_score`：取空间通路、一阶图谱、二阶图谱里面最大的扩展加分，不叠加

## 九、通路开关组合模式

1. **精准检索模式**
    - 二阶图谱关闭
    - `space_max_tree_distance=0`（仅同抽屉）
2. **模块内宽松检索**
    - `space_max_tree_distance=1`（同柜子）
    - 二阶图谱关闭
3. **深度问答增强模式**
    - `graph_second_pass_from_space = true`
    - `graph_max_depth=3`(谨慎调大，防止召回爆炸)

## 十、关键设计原则复盘

1. **空间只负责静态文件夹召回，实体只用来做层内重排序，不做扩散**
2. **全部实体推理、动态学习、跨文件夹联想能力交给图谱BFS**
3. 空间结果可以投喂图谱，图谱结果禁止投喂空间，单向数据流，避免失控
4. 二阶图谱天然增加衰减系数，保证原始种子线索优先级最高
5. 查询与学习完全分离，学习异步后置，保证检索响应速度
