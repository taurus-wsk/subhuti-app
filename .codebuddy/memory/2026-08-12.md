## 新增 HTML 报表生成器（src/report/）

用户需求：每次 HTTP 请求后，在 report 目录自动生成 HTML 报表，文件名用时间格式命名，在 tests 下创建测试。

完成内容：
- `src/report/mod.rs`：`generate()` 入口 + `build_filename()` 时间格式命名 + 净化
- `src/report/renderer.rs`：`render_html()` 纯函数，将 `SpanData[]` 渲染成深色主题 HTML 报表
- `src/lib.rs` 注册 `pub mod report`
- `tests/report_generator_test.rs`：8 个测试全通过

关键设计：
- 文件命名：`trace_{YYYYMMDD_HHMMSS}_{millis}_{trace_id净化前缀}.html`
- 净化函数 `sanitize_id_prefix`：只保留 ASCII 字母数字下划线，`take(8)` 截断，避免多字节 UTF-8 字节切片 panic、避免文件名含 `-`
- renderer 的 meta 卡片 `get()` 对字符串去 JSON 引号、数组转逗号分隔

现状说明：
- 报表是 mock 预览，数据来源 `SpanData`（框架 EventBus 事件转换而来）
- 尚未接入"每次 HTTP 请求自动落盘"——只实现了生成器 + 测试。接 HTTP 需在 trace 完成回调里调用 `report::generate()`。
- 用户提到的"函数执行内存变化采集"尚未实现（SpanData 无内存字段）

## 报表改为火焰图样式（renderer.rs 重写）

用户反馈：原报表是时间线列表，要求改成火焰图（flame graph）样式。

重写 `src/report/renderer.rs`：
- 横向时间轴：每个 span 的 bar 宽度 = 耗时占比（`left:%` + `width:%` 定位）
- 纵向调用栈：按 depth 分行（`.flame-row`），子 span 堆叠在父 span 下方
- 颜色编码：user_message 蓝、chain_selected 紫、agent_started 黄、agent_completed 绿、agent_failed 红、graph 青、flow 浅蓝、llm 紫、tool 橙
- 点击 bar 触发 `showDetail(i)`，底部详情面板显示 input/output/tokens/extra
- `build_flame_tree()` 构建 span 树（复用 observer_adapters.rs 的嵌套规则：user_message→root, chain_selected→root child, agent_*→chain child, graph/node/flow 各自嵌套）
- `FlameNode.children: Vec<usize>` 存子节点索引（非嵌套结构，避免所有权复杂度）
- mock 测试数据带时间偏移（`ts_offset_ms` 参数），模拟真实调用栈：user_message → chain_selected → agent_started → llm_call → llm_response → tool_call → agent_completed

8 个测试全通过。生成预览：`report/trace_20260812_234304_435_preview0.html`
